rclone-oci-vm Privacy Policy

Last updated: November 6, 2026

rclone-oci-vm is used only by its owner, on the owner's own server.

  • Data accessed: files in the owner's Google Drive, accessed through the Google Drive API so the owner can back up and sync them.
  • Storage: OAuth tokens are stored only on the owner's server, in a file that only the owner's account can read.
  • Sharing: no data is sold, shared with, or transferred to any third party.
  • Use: Google user data is used only to provide the backup and sync function described above. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access: access can be revoked at any time at https://myaccount.google.com/permissions.
